API 接口

点击接口可查看用途、请求参数和主要返回内容。

GET /api/v1/tags 获取标签 ID、类型、邮箱数、成功次数及裂变上限

不需要 X-Client-ID，但仍需 HTTP Basic 认证。

{
  "tags": [
    {"id": 4, "name": "Openai", "kind": "service", "count": 598, "success_count": 12, "prevent_reuse": false, "alias_use_limit": 5}
  ]
}
POST /api/v1/workbench/claim-next 按分类领取注册邮箱

必须发送 X-Client-ID。同一客户端重复调用会恢复当前邮箱，不会误跳号。

{
  "category_id": 4,
  "target_tag_id": 2,
  "address_mode": "icloud_alias"
}

category_id 是来源标签，target_tag_id 必须是平台标签。成功获取验证码后，服务端会自动追加该平台标签。

address_mode 可用 primary 或 icloud_alias。裂变模式支持同一主邮箱重复用于同一平台，但只有当前最新裂变地址可以实时轮询新邮件。

响应包含 registration_email、latest_code、latest_email.subject，以及完整的 latest_email.content 和 latest_email.text。

GET /api/v1/workbench/current 查询当前客户端领取

使用相同的 X-Client-ID 查询当前邮箱、最新验证码和最新完整邮件。

POST /api/v1/workbench/complete 记录成功接码并领取下一条 
{
  "mapping_id": 123,
  "category_id": 4,
  "prevent_shared_pool": false
}

只有确实获取到验证码后才能完成。平台取自领取时的 target_tag_id，无需再次传入，成功事件与平台标签会原子写入。

prevent_shared_pool 为 true 时将主邮箱设为禁止复用。

POST /api/v1/workbench/skip-current 释放当前邮箱并领取下一条 
{
  "mapping_id": 123,
  "category_id": 4,
  "address_mode": "icloud_alias",
  "prevent_shared_pool": false
}

服务端会先检查验证码：未到码时才释放；已经到码时会按领取时的平台标签记录成功，防止通过“跳过”绕过成功流水。
